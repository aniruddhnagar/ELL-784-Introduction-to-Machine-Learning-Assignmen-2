
Instructions to run the code:


========================Jupyter Notebook==================================

1. Open the code file in 'jupyter notebook'

2. Install the necessary libraries from the "requirements.txt",
   using following command:
	
		>> pip install -r requirements.txt  

3. Load the dataset through in-file commmand (NOTE: internet connection required).

4. Now the code can be executed in a sequential manner.

=========================Google Colab=======================================

1. Open the code file in 'Google Colab'.

2. Install the necessary libraries from the "requirements.txt",
   using following command:
	
		>> !pip install -r requirements.txt  

3. Load the dataset through in-file commmand (NOTE: internet connection required).

4. Now the code can be executed in a sequential manner.
